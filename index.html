How hybrid inference is used

  • Summarize → PREFER_ON_DEVICE (Gemini Nano in Chrome; private, offline, free) — long notes (>~3k tokens) switch to PREFER_IN_CLOUD.
  • Flashcards → PREFER_IN_CLOUD for structured JSON quality, with on-device fallback.
  • Private mode → ONLY_ON_DEVICE: sensitive notes never leave the device; the app errors instead of silently using the cloud.
  • All AI calls go through Firebase AI Logic (firebase/ai) with App Check enforced. No other model APIs.
